# Dc-Dev Caveman
Trigger: context or result transport exceeds its budget.
Workflow: choose lite/full/ultra → measure loss → retain original → retrieve on clarity escalation.
Failure behavior: helper failure falls back to uncompressed content; security, approval, and irreversible text is never compressed.
Result Contract: mode, original/retrieval handle, loss budget, measured savings, fallback.
