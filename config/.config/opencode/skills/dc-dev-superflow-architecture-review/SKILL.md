# Dc-Dev Architecture Review
Trigger: planning or a cross-domain integration checkpoint.
Workflow: compare options → record decision fitness → reject unnecessary scope → verify owned boundaries.
Failure behavior: unresolved tradeoff or scope expansion becomes `REVISE`.
Result Contract: options, decision, YAGNI ledger, boundary findings, verdict.
