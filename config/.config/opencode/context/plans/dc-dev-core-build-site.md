## Topology (quality strategy)
- **Single visible entry**: `dc-dev` (`mode: agent`). Triage, experience-mode, dispatch
  admission, result capture, and receipt are **phases of `dc-dev`**, not a visible family.
- **Single hidden worker**: `dc-dev-worker` (`mode: subagent`, `hidden: true`). No other subagent.
- **No `dc-dev-superflow-*`** agents/skills are wired, renamed, edited, or reactivated
  (archive-only — see `T-000`). Legacy `cavekit-*` / `gentle-orchestrator` / `sdd-*` are
  reference-only and untouched. `plugins/agent-flow-tts.ts` is preserved intact (R2).
- **Cycle resolution (contract-first)**: the kit's declared dependencies contain a
  forward cycle `R4 ↔ R11` (R4 lists R11/R14; R11 lists R4). Resolved by extracting the
  data contracts into `T-001` (Result Contract enum + Receipt 8-field schema) as a
  Tier-0 contract; R4 and R11/R14 now depend on `T-001`, never on each other. Graph is a
  DAG, ready for Make.
- **Waves**: conservative (one layer at a time); quality adds a per-layer verification
  task and granular sub-tasks for the heavy requirements (experience-mode R5–R8,
  dispatch/receipt R9–R18, triage R19–R25).
